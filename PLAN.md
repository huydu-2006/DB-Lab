# Plan

Build the `backend/` REST API using **Python 3.12 + FastAPI** connected to a **MySQL 8.0+ (InnoDB)** database, and integrate **Clerk + Google OAuth** authentication across the React frontend and FastAPI backend to replace the mock data in [data.ts](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/lib/data.ts) and stubbed auth in [auth.ts](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/lib/auth.ts).

## Scope

- **In:**
  - **MySQL 8.0+ Schema & Triggers (`backend/sql/`):** Normalized DDL for `USERS`, `FIELDS`, `PRICING_RULES`, `BOOKINGS`, `SERVICES`, `BOOKING_SERVICES`, `PAYMENTS`, and `MAINTENANCE_LOGS`, including `CHECK` constraints, `BEFORE INSERT`/`BEFORE UPDATE` triggers to block overlapping time slots, and seed data for the 8 stadium pitches.
  - **Python 3.12 + FastAPI Backend (`backend/app/`):** Clerk RS256 JWT/JWKS authentication & user synchronization (`clerk_user_id` → `USERS`), RBAC dependencies (`CUSTOMER`, `STAFF`, `ADMIN`), ACID transactional booking/service/payment endpoints, and SQL analytical reports.
  - **React + Clerk Frontend (`frontend/src/`):** `@clerk/clerk-react` integration with Google OAuth sign-in in [Login.tsx](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/pages/Login.tsx), typed API client (`frontend/src/lib/api.ts`), live pitch/slot/booking integration in [Dashboard.tsx](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/pages/Dashboard.tsx), [BookingDialog.tsx](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/components/BookingDialog.tsx), and [MyBookings.tsx](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/components/MyBookings.tsx), plus Staff/Admin management & revenue views.
  - **Testing:** `pytest` backend test suite (including overlap-trigger and transaction rollback verification) and frontend unit tests ([booking.test.ts](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/lib/booking.test.ts), [format.test.ts](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/lib/format.test.ts)).
- **Out:**
  - External payment gateway merchant settlement (deposits and full payments are recorded directly in the MySQL `PAYMENTS` table).
  - Native mobile applications.

## Action Items

- [ ] **Scaffold Python 3.12 FastAPI backend:** Create `backend/pyproject.toml` (or `backend/requirements.txt`), `backend/.env.example`, and `backend/app/main.py` with `fastapi`, `uvicorn[standard]`, `sqlalchemy`, `pymysql`, `cryptography`, `PyJWT`, `httpx`, `pydantic-settings`, and `pytest`.
- [ ] **Write MySQL 8.0+ DDL schema and overlap triggers:** Create `backend/sql/01_schema.sql` defining the 8 InnoDB tables (`USERS` with `clerk_user_id`, `FIELDS`, `PRICING_RULES`, `BOOKINGS`, `SERVICES`, `BOOKING_SERVICES`, `PAYMENTS`, `MAINTENANCE_LOGS`), `CHECK` constraints, composite indexes on `(field_id, booking_date, start_time, end_time)`, and `trg_bookings_no_overlap_ins` / `trg_bookings_no_overlap_upd` triggers raising `SIGNAL SQLSTATE '45000'` on slot conflicts.
- [ ] **Write MySQL seed data script:** Create `backend/sql/02_seed.sql` and `backend/app/db/init_db.py` to seed the 8 pitches from [data.ts](file:///d:/ICT-K69/20261%20semester/Database%20lab/Final%20project/DB-Lab/frontend/src/lib/data.ts), prime/standard `PRICING_RULES`, matchday `SERVICES` (Water, Ball Rental, Bibs, Referee), and initial sample bookings/accounts.
